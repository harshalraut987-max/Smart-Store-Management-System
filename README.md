# Smart-Store-Management-System
Project Overview

The Smart Store Management System is a Python-based application designed to simplify store operations. It helps manage product details, maintain stock levels, process customer purchases, calculate total bills, and record sales history.

Features
1) Product and inventory management
2) Automatic bill calculation
3) Stock quantity updates after purchases
4) Sales history tracking
5) Purchase date and time recording
6) Remaining stock information

Technologies Used
Python
streamlit and pandas
Visual Studio Code
Git and GitHub

Objective
The main objective of this project is to make store management easier, faster, and more organized by automating basic inventory and sales operations.

Future Enhancements
1) Graphical User Interface (GUI)
2) Database integration
3) User login and authentication
4) Sales reports and analytics
5) Low-stock alerts
